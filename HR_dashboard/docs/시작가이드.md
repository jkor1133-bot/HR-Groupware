# HR Dashboard 시작 가이드

비전공자도 따라 할 수 있도록 정리한 안내입니다.

## 이 폴더가 하는 일

`cursor_project/HR_dashboard`는 인사팀을 위한 대시보드 프로젝트입니다.
지금은 **주간업무계획**을 보고, 추가하고, 수정하는 기능부터 시작합니다.

## 실행 방법 (개발 환경)

1. 터미널에서 이 폴더로 이동합니다.
2. `npm install` (처음 한 번)
3. `npm run dev`
4. 브라우저에서 안내된 주소(기본 `http://127.0.0.1:4321`)를 엽니다.

## 화면에서 할 수 있는 것

- 지난주 / 이번 주 / 다음주 이동
- 업무 추가 · 수정 · 삭제
- 담당자 · 상태 필터
- JSON 내보내기 / 불러오기 (팀 공유·백업용)
- 샘플 데이터로 초기화

## 데이터가 어디에 저장되나요?

지금은 **브라우저 localStorage**에 저장됩니다.
같은 컴퓨터·같은 브라우저에서만 유지됩니다.
팀 공용 저장소(서버/DB)는 다음 단계에서 함께 업그레이드할 수 있습니다.
