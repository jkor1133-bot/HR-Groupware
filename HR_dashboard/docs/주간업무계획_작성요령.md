# 주간업무계획 작성 요령

인사팀이 매주 같은 기준으로 계획을 적을 수 있게 돕는 가이드입니다.

## 한 건의 업무에 넣을 항목

| 항목 | 설명 | 예시 |
|------|------|------|
| 업무명 | 한눈에 分かる 제목 | 신입 온보딩 Day1 체크리스트 |
| 상세 내용 | 실제로 할 일 | 계정·장비·환영 키트 준비 상태 점검 |
| 담당자 | 실행 책임자 | 이하늘 |
| 카테고리 | 업무 성격 | 온보딩 |
| 우선순위 | 높음 / 보통 / 낮음 | 높음 |
| 상태 | 예정 / 진행 중 / 완료 / 지연 | 진행 중 |
| 목표 요일 | 월~금 중 목표일 | 월 |

## 좋은 업무명의 예

- ✅ `개발직군 서류 스크리닝`
- ✅ `월중 급여 변동분 검토`
- ❌ `여러 가지 처리` (무엇을 하는지 모호함)
- ❌ `회의` (결과물이 보이지 않음)

## 주간 리듬 추천

1. **월요일**: 이번 주 업무를 등록하고 우선순위를 맞춥니다.
2. **수요일**: 진행 중 / 지연을 점검하고 상태를 갱신합니다.
3. **금요일**: 완료 여부를 확인하고 JSON으로 주간 백업을 남깁니다.

## 팀 공유 팁

1. 금요일에 **JSON 내보내기**로 파일을 저장합니다.
2. 공유 폴더에 `주간업무_YYYY-MM-DD.json` 형식으로 올립니다.
3. 다음 주 월요일, 필요하면 **JSON 불러오기**로 이어서 작업합니다.
